# Hotel Management System

A desktop-based Hotel Management System built with Python and Tkinter to simplify hotel operations, including room booking, guest management, staff management, housekeeping, and revenue tracking.

## Project Overview

The Hotel Management System provides a user-friendly dashboard for managing essential hotel activities efficiently.

### Features

- **Book Room** – Manage guest room reservations.
- **Checkout** – Process guest checkouts.
- **Search Guest** – Find guest information.
- **Room Status** – Monitor room availability.
- **Staff Management** – Manage hotel staff.
- **Booking History** – View previous bookings.
- **Update Booking** – Modify reservation details.
- **Housekeeping Status** – Track room cleaning status.
- **Revenue Report** – View revenue summaries.

## Technology Stack

- Python
- Tkinter
- JSON
- Python Standard Library
